# Rasmlar

`hero_car.png` — xush kelibsiz ekranidagi bosh sovrin (Chevrolet Cobalt) rasmi.

- Shaffof fonli PNG (fon olib tashlangan), mashina yon tomondan yoki 3/4 burchakdan.
- Tavsiya etilgan o'lcham: eni kamida 1600 px.
- Fayl bo'lmasa, chizilgan vaqtinchalik siluet ko'rsatiladi.
- Hozirgi rasm: foydalanuvchi bergan studiya surati (1200x800), foni Mac'dagi
  Vision vositasi bilan olib tashlangan. Nisbati o'zgarsa,
  `lib/widgets/prize_car_hero.dart` dagi `aspectRatio` ni ham yangilang.
- Rasmdan foydalanish huquqi bo'lishi kerak (o'zingiz olgan surat yoki
  buyurtmachi bergan rasmiy material).
